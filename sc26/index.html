SC26 tutorial

Dagger.jl tutorial console

One command installs the tutorial, logs you in to Odo, and opens the console in your browser.

You need

An OLCF account with access to Odo, and your PASSCODE (PIN followed by the RSA token code). Nothing else: no Git, no GitHub account, and no Python or Julia on your computer.

macOS or Linux

Open a terminal and run:

curl -fsSL https://fda-tome.github.io/sc26/install.sh | sh
  1. It downloads the tutorial into ~/sc26-dagger. If you have no Python 3.9 or newer, it also puts a private one there; it needs no administrator rights.
  2. It asks for your OLCF username, then for your PASSCODE to log in to Odo.
  3. It opens the console at http://127.0.0.1:8767. Keep the terminal open while you work; close it to stop.

Run the same command again to update the tutorial and start again. Your results and your exercise/my_cholesky.jl are kept.

Windows

The console needs an SSH feature that Windows' own ssh lacks, so it runs inside WSL (Linux on Windows):

  1. Once: open PowerShell as administrator, run wsl --install, and restart.
  2. Open Ubuntu from the Start menu and run the command above there.
  3. If no browser opens, go to http://127.0.0.1:8767 in Windows.

What it changes on your computer

Everything lives in ~/sc26-dagger, except one marked Odo entry the console adds to ~/.ssh/config and its connection file in ~/.ssh/control/. To remove it all, delete ~/sc26-dagger and that marked entry. Read the script first: install.sh.
