SC26 tutorial · dry run

Dagger.jl tutorial console, dry run

One command installs the dry-run version of the tutorial, connects to andromeda, and opens the console in your browser.

You need

An account on andromeda (andromeda.lasdpc.icmc.usp.br, SSH port 21200) that logs in with your SSH key, and a Slurm association there: every run is a Slurm job, so ask the administrator if srun says “Invalid account”. Nothing else: no Git, no GitHub account, and no Python or Julia on your computer.

macOS or Linux

Open a terminal and run:

curl -fsSL https://fda-tome.github.io/sc26-dry-run/install.sh | sh
  1. It downloads the dry-run tutorial into ~/sc26-dry-run. If you have no Python 3.9 or newer, it also puts a private one there; it needs no administrator rights.
  2. It asks for your andromeda username and connects with your SSH key; there is no password.
  3. It opens the console at http://127.0.0.1:8767. The first connection installs Julia and the packages on andromeda, which takes a few minutes. Keep the terminal open while you work; close it to stop.

Run the same command again to update the tutorial and start again. Your results and your exercise/my_cholesky.jl and exercise/my_stencil.jl are kept.

What the dry run changes

  1. andromeda instead of Odo. One node with two NVIDIA A30 GPUs, so the GPU code uses CUDA where the course uses AMD GPUs.
  2. No node to allocate. Every demo, exercise and REPL evaluation is its own Slurm job with the CPUs and GPUs it needs, and nothing is held between runs.
  3. A Stencils section, with a demo of @stencil and a heat-diffusion exercise.
  4. The final exercise is still Gray-Scott, now with a stencil for its explicit terms and Cholesky for its implicit ones.

For the course itself, use the SC26 tutorial page.

Windows

The console needs an SSH feature that Windows' own ssh lacks, so it runs inside WSL (Linux on Windows):

  1. Once: open PowerShell as administrator, run wsl --install, and restart.
  2. Open Ubuntu from the Start menu, put your andromeda key in ~/.ssh there, and run the command above.
  3. If no browser opens, go to http://127.0.0.1:8767 in Windows.

What it changes on your computer and on andromeda

On your computer everything lives in ~/sc26-dry-run, except one marked andromeda entry the console adds to ~/.ssh/config and its connection file in ~/.ssh/control/. It does not touch the SC26 page's Odo entry. On andromeda it uses ~/sc26-dagger: Julia, the packages (about 4 GB) and the workspace. To remove it all, delete those two folders and the marked entry. Read the script first: install.sh.
